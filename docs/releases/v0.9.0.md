Omniaware — OA for short — now reads the text in your pictures. Everything below was tested on Windows 11 before release.

## New

**Text in images.** Every screenshot and pasted picture is read in the background with the text recognition built into Windows, so `Ctrl+K` finds the error message in last week's screenshot (the hit reads *in image · …*). Right-click a picture, or use the enlarged view's toolbar, and choose **copy text** to put its text on the clipboard. Nothing leaves the machine, and nothing stays loaded: each picture is read by a short-lived helper process at low priority, so Omniaware's background cost is unchanged. Existing pictures are read once, newest first, a few seconds apart.

**A cleaner main window.** Search sits in the middle of the top bar. `Ctrl+B` folds the left column (views and calendar) into a slim tab, like the shortcut panel; the choice is remembered.

**OA.** The short name gets a mark of its own: "OA" in JetBrains Mono ExtraBold in the theme's accent colour, with "Omniaware" beside it while the name settles in. The window title and tray tooltip read "OA · Omniaware".

**F1 in the quick note** now opens and closes the shortcut overlay instead of showing it only while held. `F1`, `Esc`, any other key or a click closes it, a quick double tap does not, and the arrow keys, `PgUp`, `PgDn`, `Home` and `End` scroll it.

**Benchmark kit.** Each CI build includes `oa-probe.exe`, a small tool that measures what Omniaware costs on a machine over a day or three (CPU, memory, GPU memory, handles, threads), next to a description of the hardware. It runs a separate benchmark copy that leaves a real Omniaware alone. See *Measuring resource use* in the README.

## Fixed

- **A crash after some notices.** A notice without an "open" link — *Text copied*, *Exported*, *No text found* — could close Omniaware without a word. This has been there since 0.5 and showed up now that such notices are common.
- **Crashes are no longer silent.** Should Omniaware ever close unexpectedly, the reason is written to `omniaware.log` and shown in a notice the next time it starts.

## Upgrading

Replace `omniaware.exe`, or run `scripts\install.ps1` again. The database and `config.toml` are updated on first start (a new `[ocr]` section; set `enabled = false` to turn text recognition off). If your Windows display language has no OCR component, add it under *Settings → Time & language → Language & region → (language) → Language options*.
